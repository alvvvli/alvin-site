Plant Builder

A more interactive AGV flow simulator with edit mode, draggable assets, routing, congestion, live KPIs, and station state changes. Built from your existing JS structure and expanded into a plant-style sandbox.

Modes

In build mode, click to place assets. In select mode, drag assets to re-layout the plant while the simulation is running.
